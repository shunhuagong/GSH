# 《仨》游戏策划案（GDD）

- 项目代号：WeGame ｜ 状态：概念确立 ｜ 版本：v0.1 ｜ 日期：2026-10-16
- 本文档由立项讨论整理而来，是项目的第一份文档，后续以修订记录方式持续更新。

---

## 1. 项目初衷

我们三个人，怀念大学时光，毕业后也想在一起生活工作。这个游戏既是**我们友谊的纪念品**，也是**一次"做游戏"的共同冒险**——用业余时间，从零基础开始，把我们的故事做成一个能玩的东西。

所有设计决策服从一个前提：**最重要的产出是"我们一起做它的过程"，其次才是游戏本身。**

## 2. 一句话概念

> 毕业后我们仨合租在一起，白天共同经营一家小店，晚上在回忆里重回大学时代——把"想一直在一起"这个愿望，做成一款本地三人合作的 2D 像素经营叙事游戏。

| 项 | 设定 |
|---|---|
| 类型 | 合作经营 × 回忆叙事小品 |
| 人数 | 1~3 人，本地同屏（单人可切换角色） |
| 平台 | PC / Mac 先行（Steam / itch），远期考虑移动端 |
| 美术 | 2D 像素风，AI 生成为主 + 真实素材彩蛋 |
| 引擎 | Unity（Mac 开发） |
| 节奏 | 业余长线项目，小步快跑，每个阶段都有可玩成品 |

## 3. 体验支柱（所有设计取舍的准绳）

1. **在一起** —— 核心玩法需要三个人协作；不做联机的阶段就用本地同屏，保证"我们仨挤在一台电脑前"的体验。
2. **回忆即内容** —— 关卡不是关卡，是我们真实发生过的事。
3. **失败不可怕** —— 全程无 Game Over 惩罚：当天亏钱就吃泡面，日子照样过。

## 4. 游戏循环

### 4.1 日常循环（一天 = 一个游玩单元）

```
白天经营（10~15 分钟一局）
   → 傍晚结算（收入、默契值）
   → 合租屋（夜谈 / 触发回忆关卡）
   → 睡觉存档
```

### 4.2 大循环：四季章节 × 大学四年

游戏进程分春夏秋冬四章，"现在的日子"与"过去的时光"互为镜像，玩到冬天时情绪拉满。

| 章节 | 店铺线（现在） | 回忆线（过去） |
|---|---|---|
| 春 | 小店开张，学会基本功 | 大一：军训、初识、社团招新 |
| 夏 | 旺季客流、天气事件 | 大二：通宵 DDL、卧谈会、看烟花 |
| 秋 | 菜单升级、老客出现 | 大三：实习面试、第一次争吵 |
| 冬 | 年关盘点、店庆 | 大四：散伙饭、毕业旅行 |

## 5. 白天：经营线

### 5.1 三个岗位

一人一岗，缺谁都不行——玩法本身就是"在一起"的隐喻。

| 岗位 | 职责 | 玩法要点 |
|---|---|---|
| 接单 | 收银、记住客人需求 | 读顾客气泡、传递订单 |
| 制作 | 按订单做商品 | 小组合工序，节奏压力 |
| 招呼 | 引导入座、安抚等待的客人 | 走位与优先级判断 |

**轮岗制**：每局手动或随机换岗，让三个人都体验彼此的活——"你终于知道我多累了"。

### 5.2 默契值与合体技

- 合作无失误（不落单、不漏接、互相递东西）积累**默契值**；只靠"一起玩"才能涨，是三人感情的数值化。
- 默契值满触发**合体技**：如全店慢动作、三人合唱提升客人耐心。
- 默契值同时作为部分回忆关的解锁条件（见 §6.1）。

### 5.3 客人系统

- **普通客**：提供日常客流压力。
- **常客支线**：总来写稿的落魄作家、每周三来吵架又和好的小情侣——有小段故事可跟进。
- **彩蛋客人**：老同学、辅导员、当年社团的学长学姐，认出他们时对话会变。

### 5.4 事件卡

每局随机事件保证新鲜感：台风天（客人骤减，可提前备材）、排队高峰、设备故障（一人离岗去修）。

### 5.5 愿望清单（经济的真正去向）

钱不只用来升级店铺。三人合议攒钱买"没用的快乐"：

- 投影仪 → 解锁"周五电影夜"小场景
- 猫 → 会抓店里老鼠（衍生小玩法）
- 去海边的旅行基金 → 对应毕业旅行回忆关

把"终极目标"拆成一个个共同盼头，而不是一个冷冰冰的金额数字。**攒够钱把小日子过下去——和"毕业后想在一起生活"的愿望完全同构。**

## 6. 夜晚：回忆线

### 6.1 解锁机制

- 赚到的钱兑换**回忆券**。
- 部分回忆需要**条件触发**，让回忆像真实回忆一样不期而至：下雨天的夜里才想起军训；默契值满的那天才解锁卧谈会。

### 6.2 回忆关卡表（每关一种新玩法）

回忆关卡做成"小游戏合集"，既是玩法调节器也是叙事本体。

| 回忆 | 时期 | 玩法类型 | 情绪点 |
|---|---|---|---|
| 军训 | 大一 | 节奏 / QTE（站军姿别晃、拉歌对拍子） | 又累又好笑 |
| 社团招新 | 大一 | 三选一的抉择互动 | 初见的热血 |
| 食堂抢座 | 大一 | 格子抢位谜题，还要帮室友占座 | 烟火气 |
| 通宵赶 DDL | 大二 | 资源管理（咖啡 vs 睡眠条，最后关头打字如飞） | 患难与共 |
| 卧谈会 | 大二 | 互动小说式对话；场景光照随聊天缓慢变亮 | 全游戏最安静的一关 |
| 实习面试 | 大三 | 轻对话 + 模拟抉择 | 第一次感到未来压近 |
| 第一次争吵 | 大三 | 无玩法纯剧情（全游戏唯一"不能操作"的关） | 记得和好那天 |
| 散伙饭 | 大四 | 纯剧情 | 眼泪 |
| 毕业旅行 | 大四 | 纯探索步行，不设失败 | 自由 |

> 回忆清单需从三人真实经历中盘点改编（见 §15 待定决策）。

## 7. 合租屋（白天与夜晚之间的枢纽）

第三空间，一个可自由走动的小家：

- **夜谈**：睡前三人瞎聊，对话池随章节推进变化。
- **照片墙**：每完成一段回忆，墙上多一张"拍立得"，装饰全靠玩出来。
- **生日系统**：开档时输入三人真实生日，到了那天店里会有惊喜事件。
- **装饰系统**：回忆关卡掉落的物品（军训水壶、社团传单）可摆进家里。

## 8. 情感设计细节（低成本高感动）

- **开场即散伙饭**：黑屏字幕"毕业那天你们说，以后一定要住在一起"→ 淡入小店开张，点题。
- **不设 Game Over**：经营失败的代价是"今晚吃泡面"，这游戏的失败不该是挫败。
- **真实录音**：夜谈与回忆关可用三人真实录音（手机录即可）；AI 语音生成做日常台词。
- **真实素材**：照片、聊天记录以彩蛋形式藏进照片墙与回忆关。

## 9. 章节与内容量

- 全量愿景 = 4 章 ×（店铺阶段玩法 + 2~3 个回忆关）+ 合租屋系统。
- 回忆关卡是独立小单元，做完一个加一个，永不"做不完"——这是本项目抗弃坑的核心结构。

## 10. 美术与音频方向

- **2D 像素风**：AI 生成最成熟、最不容易穿帮的风格；三人像素立绘以你们自己为原型。
- **美术基准**：参考《星露谷物语》的画风与氛围——俯视 45° 视角、方块网格、低饱和暖色调、四季调色板、二头身角色比例。**只借画风，不借玩法结构**（玩法维持 §4 章节化设计）。此风格约定对 AI 生成尤其友好：参考样本海量、风格容易统一。
- **工作流**：AI 生成 → 统一调色板 → 手动修关键帧（角色、UI）；场景允许更粗的生成质量。
- **音乐**：以原创 / 可商用素材为主（毕业歌单做"歌单企划"彩蛋而非直接使用，规避版权问题）。
- **音频**：夜谈、关键回忆优先用真实录音。

### 10.1 角色设计工作流（照片 → 像素小人）

**资产规格（星露谷同款约定）**

| 资产 | 规格 | 用途 |
|---|---|---|
| 身体精灵 | 16×32 px，二头身，四方向行走各 3~4 帧 | 店内 / 场景行走 |
| 对话头像 | 64×64 px | 夜谈、回忆关对话 |
| 表情差分 | 笑 / 惊 / 困 / 气 / 平静，先做 4 种 | 头像差分 |
| 辨识设计 | 每人固定主色 + 1~2px 身高差 | 挡脸看剪影也可辨认 |

**转译原则**：特征提纯，不做照片还原——像素小人只有几十个点，塞不下"像本人"，只能"认得出本人"。每人保留 2~3 个标志性特征并夸张化。验收标准：**三人互相一眼认出"这是我"；挡脸看剪影也认出 = 过关**。

**性格 → 岗位映射**（有轮岗制兜底，此为默认分工 + 各自标志小动作）

- 最外向、记性好的 → **接单**
- 最细心、手巧的 → **制作**
- 最有耐心、爱张罗的 → **招呼**

**照片收集标准**（越不正式越好；证件照 / 精修照 / 强滤镜是雷区——磨皮与规范姿态会抹掉辨识特征）

| ✅ 优先要 | ❌ 避开 |
|---|---|
| 每人 2~3 张：正面 1 + 侧面（45°/90°）1 | 证件照、形象照、精修照 |
| 白天自然光、不逆光 | 强美颜 / 强滤镜 |
| 休闲穿搭、平时的样子（"他总穿的那件"就是设计素材） | 逆光、夜景糊图 |
| 自然表情、有笑的抓拍 | 只剩脸的裁切图、糊在一起的合照 |
| 露出发型（帽子本身是标志则反之） | |

**随照片补充**：① 三人身高排序（照片看不出相对身高）；② 每人一个"人尽皆知的标志物"（口头禅、常戴的耳机、表情包行为）→ 转化为游戏内标志小动作。

**工作流与分工**

```
照片收集（存 assets_ref/，仅作设计参考，不进游戏资源目录）
  → 特征分析 + 《角色设定卡》（特征清单 + AI 绘图提示词）
  → AI 绘图工具出图（即梦 / 豆包 / Midjourney 任选）
  → 审图迭代 2~3 轮
  → Piskel（免费网页版）或 Aseprite 修补成可用精灵图
  → 脚本统一调色板、去杂点、整数放大
```

> 照片涉及三人肖像，仅用于本项目设计参考；对外发布相关素材前需三人共同确认。

## 11. 技术方向

- Unity 2D（Mac 开发），本地多人：键盘分键位 + 手柄支持。
- 单人模式 = 随时切换三个角色（Overcooked 式）。
- 存档：一个存档位 + 云存档意向。
- 架构上为远期联机预留接口（岗位状态分离），但 v1/v2 不做联机。
- 全程中文，UI 文案集中管理。

## 12. 版本规划与范围控制

> ⚠️ 范围控制原则：**v1 清单冻结**。任何新点子一律先记入"愿望清单"，不进当期排期。

### v0 练手（不产出正式内容）
装引擎、跟完官方 2D 入门教程、做一个小练习（像素走路 / Pong）。

### v1 · 礼物版（MVP，也是第一份可送出的成品）
- 一家店：单一场景，6~8 种商品
- 三岗位玩法 + 本地同屏三人（或单人切换）
- **3~5 个回忆关**：建议军训、通宵 DDL、食堂抢座、卧谈会、散伙饭
- 照片墙 + 简单夜谈
- 一个结局画面
- 目标形态：某人生日或某个节日送出

### v2 · 完整版
- 四季章节全量、默契值 / 合体技、事件卡、常客支线
- 愿望清单经济、生日系统、装饰系统

### v3 · 梦想清单（先不做）
- **联机模式**："异地同玩"——联机在这里不只是功能，是对"毕业后可能分隔三地"这件事的回答
- 移动端、周年 / 续章 DLC、三人真实录音替换全部台词

## 13. 路线图（零基础起步）

| 阶段 | 时间（估） | 交付 |
|---|---|---|
| 0 练手 | ~2 周 | 引擎环境 + 入门教程完成 |
| 1 礼物版 | 1~2 个月 | 单人可玩的"回忆收集"小作品 |
| 2 MVP | 3~6 个月 | 经营玩法 + 本地三人合作，达成 v1 清单 |
| 3 完整版 | 长线 | 四季全章节 |

## 14. 风险与对策

| 风险 | 对策 |
|---|---|
| 零基础，进度慢 | 每阶段设小目标；三人轮流主导当周的活；不比速度比坚持 |
| 范围蔓延 | v1 清单冻结制，新点子只进愿望清单 |
| 回忆内容难产 | 每人先写 5 段最想留住的大学记忆，建立素材库（见 §15） |
| AI 素材版权 | 只用可商用生成工具；对外发布前统一盘点素材来源 |
| 热情冷却 | 每个阶段产出"能玩 / 能看 / 能送人"的成品；夜谈里的新梗持续入库 |
