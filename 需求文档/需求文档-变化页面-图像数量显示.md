# 需求文档：“变化”页照片组角标
## 背景与现状
   “变化”页以日期分组显示照片，照片组展示方式横向滑动展示。**照片组展示三张图片第四张往后的图片需要横向拖动，照片组没有一个标记指明后面还有图片**，用户可能以为就只有三张图片。
    
## 目标交互
    **目的** 照片组右上角和同照片组日期平行显示“+n”角标作为提示，n = 当天照片总数 - 3
    
    1.**触发条件**
        - 当日照片总数 <= 3，角标不显示；
        - 当天照片总数 > 3， 角标显示；
    
    2.**数值/内容**
        - n = max(0, 当天照片总数 - 3)。例如：5张 ➡️ 显示 +2；4张 ➡️ 显示 +1； 3张 ➡️ 无角标； 2张 ➡️ 无角标。
    
    3.**位置**
        - 显示于照片组的右上方，高度同**照片组当日日期平行**，**不显示在图片上**
        
    4.**样式**
        - 圆形底：**直径 20dp**，黑色 **40% 透明度**（`Color.Black.copy(alpha = 0.4f)`）；
        - 文字：白色 **10sp**、不加粗，内容形如 `+2`（半角加号 + 数字，无空格）；
        - 若 20dp 圆内两位数（如 +10）显得挤，允许把圆改成**胶囊形（宽自适应、高 20dp）**，二选一由执行 AI 定，但字号和颜色不变。

    5.**行为**
        - 当添加/删除图片， 角标数字发生相应变化。
        
    6.**空态**
        - 当天没有添加照片 ➡️ 照片组不存在 ➡️ 不显示角标。
    
## 约束
    1.**不删除、不修改、不更新除“变化”页面以外的数据、逻辑等**。
    2.**不修改、不更新、不删除“变化”页面原本的图片显示/添加/删除/修改等逻辑**。
    3.**不引入新依赖**。
    4.**只是添加角标，不要有附加内容**。

    - [ ] 存 4 张的那天：显示 "+1"
    - [ ] 存 3 张的那天：**没有**角标；存 1~2 张同样没有
    - [ ] 角标为深色半透明圆底、白字，直径约 20dp，与日期同一行垂直居中
    - [ ] 当天再拍 1 张（5→6）：角标自动变 "+3"，无需退出页面重进
    - [ ] 拍照/选图/删除照片原有功能全部正常（回归）
