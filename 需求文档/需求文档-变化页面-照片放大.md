# 需求文档：照片组里的图片可以放大

## 背景与现状
    “变化”页面点击照片组可以查看照片，左右滑动查看其他图片。**点击查看指定图片，但是不能放大图片**，用户想放看图片的细节，并不行。
    
## 目标交互
    **一句话**点进照片组可以放大图片。
    
    1.**触发条件**
        - 点击照片组中的照片，**以照片为中心**双指向外滑动可以放大图片。
    
    2.**内容**
        - 放大这个功能只作用于当前选择的照片，不会同时放大照片组其他的照片。例如：照片组有3张图片，点击照片组第2张图片 -> 查看第2张图片 -> 双指向外滑放大图片 -> 第1张和第3张照片不受影响保持现状。
        - 双指放大范围：1.0 - 8.0 (8.0封顶)。
        - 放大后：单指可以拖动图片查看照片细节，左右滑动不支持切换图片。
        - 放大后：单指拖动图片最左边缘或最右边缘，可以切换图片。
        - 松手后保持当前倍数，不会自动弹回。
        - 缩放图片后，并切换照片，再次切换回来，将回到1倍。        
        - 拖动跟手速度 = 1 : 当前缩放倍数 * 1。即放大 4× 时，手指移动 1cm，画面内容移动 1cm；始终满速（指头到哪，内容跟到哪），不粘滞。
        - 双指向内滑 = 缩小；最小到 **1.0**（不允许低于 1 倍）。
        - **边缘切换的明确规格（追加修正 2026-10-30；2026-10-30 二次修正：与 1× 横滑的判定时机对齐）**：
            - **切换判定放在"松手时"，不在拖动中途触发**——与 1× 状态下系统横滑翻页的体验完全一致：手指没松开就不切，松手才判定落位。
            - 拖动中：图片拖到左/右边界后，继续同方向拖动**不再切换**，图片保持贴在边界（溢出量只累计、不位移）。
            - **松手时判定**：本次手势累计溢出 ≥ **60px** → 用系统 Pager 翻页动画（animateScrollToPage）切到上一张/下一张；**< 60px → 图片以 150ms 动画弹回最近边界位置**（"差一点、没切"的反馈）。
            - 一次手势最多切换一张（判定只做一次）；阈值 60px 为固定规格，不用 magic number 隐埋。
            - 切换后新照片从 1× 开始（与"切走再回来重置 1 倍"规则一致）；不做淡入淡出，沿用 Pager 原生动画。
    3.**边界**
        - 在当前展示照片范围内放大。
        - 不会影响上下的黑色边框和右上角的“删除”按钮。
        
## 约束
    1.**不修改、不删除、不扩展除“变化”页面的其他页面内容**。
    2.**不修改、不删除、不扩展“变化”页面添加/删除照片逻辑**。
    3.**不修改、不删除、不扩展“变化”页面点击图片查看指定图片逻辑，左右横滑逻辑**。
    4.**只做照片放大的功能，不附加其他功能**。
    5.**缩放手势的实现可参考『我』页头像裁剪的放大缩小逻辑，复用其手势处理方式**。
    
## 验收清单
    **用户自己验证，不需要ai验证**
    - [ ] 查看的照片双指向外，以照片为中心放大，不影响左右其他。
    - [ ] 拍照/选图/删除照片/左右滑动工程正常
    - [ ] 照片放大到2x， 右上角依然可以点击，并删除成功。
    - [ ] **放大后拖到右缘继续拖：手指未松开时不切换（图片贴在边界）；松手且累计溢出 ≥ 60px：切换到下一张，新照片为 1 倍**。
    - [ ] **拖到边缘后松手但溢出不足 60px：图片 150ms 弹回边界位置，未发生切换**。
    - [ ] **放大 4× 后拖动跟手不粘滞：手指动多快，画面跟多快（1:4 速比）**。
    - [ ] **一次手势只在边缘触发一次切换：拖到边缘连拖不会连跳多张**。
    - [ ] 双指向内滑可缩小，缩到 1 倍就停（不出现小于 1 倍的画面）。
