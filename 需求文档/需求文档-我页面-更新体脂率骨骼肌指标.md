# 需求文档：添加体脂率、骨骼肌、体重指标
    **增加指标**
## 背景与现状
    目前“我”界面没有根据时间记录**体脂率、骨骼肌、体重等指标**，用户不能看见这三个指标随时间的变化趋势。
    
## 数据层
    1.**表格结构**
    ｜时间｜体重｜体脂率｜骨骼肌
    ｜---｜---｜---｜
    ｜内容｜内容｜内容｜
    ｜内容｜内容｜内容｜
    
    体重单位kg、体脂率单位%，骨骼肌单位%。
    
    2.**记录方式**
        - 点击“添加”新建“身体记录”弹窗（体重 kg / 体脂率 % / 骨骼肌 %），放在“我”页面（见功能层）；
        - 时间是依据当天时间；
    
    3.**空值语义**
        - 没测的指标**为空，不填入数据**，**当存指标<=0，直接为空**。
    
    
## 目标交互（功能层）
    **目的**：在“我”界面创建一个卡片上面依次有**体脂率、骨骼肌、体重等指标**，并以折线图（横坐标时间/纵坐标指标）的形式展现。
    
    1.**触发条件**
        - 当用户点击“体脂率/骨骼肌/体重”字样可以跳转到对应的指标界面，并显示随时间变化的折线图。
        - 用户在相应指标界面点击添加按钮 -> 弹出窗口选择时间填入数据，并保存 -> 折线图数据立即更新。
        
    2.**折线图内容**
        - 三个指标使用同一种折线图，横坐标为时间，做坐标为指标。
        - 体重的纵坐标事先有（0，30，60，90）， 骨骼肌和体脂率纵坐标事先有（10， 15， 20）；
        - 数据点 = 又该指标的日期，标上会标注指标例如：（63.8）
        - 横坐标 = 只显示记录的时间
## 四、约束

1. **不碰饮食、训练模块**；不改底部导航。
2. **设置页 profile 体重勿动**（营养目标计算依据）；身体趋势的体重记录与 profile 体重是**两回事**，本版不做"记录体重时同步 profile"（如要同步另行拍板）。
3. 折线 Canvas 手绘，不引入图表库。
4. 身体数据只做记录与展示，**不做健康评价/建议**（体脂多少算好由用户自己判断；AI 分析接入是另一个需求）。
