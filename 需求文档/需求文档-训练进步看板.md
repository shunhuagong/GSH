## 一、现状快照（全部已落地，勿重做）

App 版本 v2.2（code 13），Room **version 9**，训练模块当前能力：

| 能力 | 现状 |
|---|---|
| 逐条训练记录 | `training_entries(date, exerciseId, weightKg?, reps?, durationSec?, createdAt)`，按天存储 |
| 录入交互 | 选动作 → 回训练页出卡片 → **行内三框 kg/次/秒**（72/56/64dp、48dp 高、无提示词、单位 suffix）→ ✓ 保存；✕ 取消丢弃 |
| 合法输入三选一 | kg+次 ｜ 只次 ｜ 只秒；其余组合 ✓ 置灰 |
| 「＋」按钮 | 只负责开下一行；**不自动保存**预填行（防误存）；待填行存在时灰显 |
| 组号 | 显示层计算（当天+动作+入库顺序），删组自动补位；「第 N 组」浅灰徽章 |
| 上次带过 | 待填行自动预填**该日期之前**最近一次的第 N 组（不足带上一组），`lastSetsOfBefore` 严格 `<` |
| 日期解耦 | 显示/录入/标记训练日均跟随 `selectedDate`；翻历史日期可补录那天（**受历史锁定约束：仅限 7 天内**，见下） |
| **历史锁定（2026-11-09 新增全局规则）** | **超过 `HISTORY_LOCK_DAYS = 7` 天的日期只读**：不可删/改/补录饮食照片、饮食条目、训练条目（防篡改历史）；7 天内的历史日期删记录弹确认，当天直接删；锁定日期的拍照/添加入口隐藏。实现位于 `GshViewModel.isDateLocked()`，训练删除前按 `byId` 查日期校验 |
| 动作分类 | `muscleGroup` 逗号分隔多标签（腿/背/胸/肩/臂/腹，"核心"已同步改"腹"）；看板/选择器按标签过滤 |
| recordType | **只剩看板口径**：新建一律 -1，首次保存按所填 settle，启动 `backfillRecordTypes` 幂等回填；已有 0/1/2 不回滚 |
| 看板 | 「我」页入口二级页：动作 chips + 最好成绩卡（较上次变化 / 🔥 新纪录）+ 近 90 天 Canvas 折线；口径=最好一组/最大次数/最长秒 |
| 卡片折叠 | 点头部折叠/展开（折叠态「动作名 · N 组」+箭头旋转动画；有待填行的卡不折叠；新卡默认展开） |
| 时长单位 | 全链路**秒**（v8→v9 已迁移：durationMin 改名 durationSec、存量 ×60） |
| 删除 | 已保存组行尾垃圾桶图标 `Icons.Outlined.Delete` 32dp |
| 进度点 | 卡片头部 4dp 圆点，N 组亮 N 个（待填行空心） |

**用户口径（长期有效）**：训练数据属实验阶段、可弃；**饮食数据必须保全**——任何操作严禁清 App 数据/卸载；不碰饮食模块、不加图表库、不改底部导航、不加账号/云同步。**历史记录超 7 天锁定只读**（2026-11-09 起），任何新功能涉及历史日期写入时先过 `isDateLocked` 这道闸。

## 三、待办二：历史页显示训练摘要（用户 2026-10-30 拍板，方案 A）

> 现状：`HistoryScreen` 每日卡片只有饮食营养条 + 💪/😴 标记，训练内容完全不可见。
> 方案 A = 历史卡片加"训练摘要行"，外加修正历史列表的数据源边界问题。

### 改动内容

1. **每日卡片加训练摘要行**（`DailyTotalCard`）：营养条下方加一行，如「🏋️ 深蹲 4 组 · 引体 3 组」：
   - 有训练记录的日子显示；无记录的日子不显示（保持卡片干净）；
   - 摘要 = 该日 `training_entries` 按动作聚合（动作名 + 组数，`组数 DESC` 排序），与今日页训练入口行同款文案格式（「X N 组 · Y M 组」）；
   - 数据查询：DAO 按日聚合训练（或复用 `observeByDate` 思路加一个 `Flow<Map<date, List<ExerciseCountOfDay>>>`，一次查历史范围避免逐日 N+1 查询，实现自选但勿在 LazyColumn 每个卡片里单独发查询）。
2. **历史列表数据源改并集**：现状 `dailyTotals`（饮食汇总）驱动列表——**只练了没吃（没记饮食）的训练日在历史页隐身**。改为"有饮食 ∨ 有训练记录"的日子都出卡片（无饮食那天营养行为空或显示"—"，训练摘要行照常显示）；排序、分页习惯不变。
3. **点卡片进单日**：现有行为（回"今日"页看该日）不动；训练卡片随日期解耦已自然显示该日训练，验收时顺带回归确认即可。
4. 文案与视觉：摘要行 12sp、`onSurfaceVariant`，加 🏋️ 前缀与 💪 训练日标签形成呼应；不引入新颜色。
